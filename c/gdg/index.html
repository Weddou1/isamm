Nom du club

Google Developer Groups On Campus ISAMM (GDG)

Cible

Étudiants de tous les cursus (licence et master), quel que soit leur niveau, intéressés par les technologies Google et le développement.

Domaine d'activité

Informatique, Innovation

Description

Le Google Developer Groups On Campus ISAMM est une communauté universitaire ouverte aux étudiants que les technologies Google et le développement intéressent. Le club accueille les étudiants de tous les cursus, licence comme master, quel que soit leur niveau de départ, et les accompagne dans leur progression de développeur.
